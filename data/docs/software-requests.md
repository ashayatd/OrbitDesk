# Software and Access Requests

> Fictional document created for the OrbitDesk demo. Orbit Systems is not a real company.

## 1. Pre-Approved Software

Software listed in **Company Portal** is pre-approved and can be installed without a ticket. This includes browsers, Slack, Zoom, VS Code, Python, Node.js and Microsoft Office.

## 2. Requesting New Software

1. Raise an IT ticket with category **"Software Request"**.
2. Include the software name, version, business reason and licence cost.
3. Your manager approves the request in the ticket.
4. IT Security reviews software that handles company data; this review takes up to **5 working days**.

Paid licences above **USD 500 per year** also need approval from your department's budget owner.

## 3. Prohibited Software

Personal cloud storage sync clients, torrent clients, and unapproved AI tools that upload company data are prohibited on company devices.

## 4. Access to Systems

Access to internal systems (for example GitLab groups or databases) is requested with category **"Access Request"**. Access is granted on a least-privilege basis and reviewed every **6 months**.

## 5. Typical Turnaround

Pre-approved software: immediate. New software: **5 to 10 working days**. Access requests: **2 working days** after manager approval.
