# Laptop Troubleshooting Runbook

> Fictional document created for the OrbitDesk demo. Orbit Systems is not a real company.

## 1. Standard Hardware

Employees receive an **OrbitBook 14** (engineering staff receive an **OrbitBook 16 Pro**). Laptops are refreshed every **3 years**.

## 2. Common Issues

### 2.1 Laptop Will Not Turn On

Connect the original charger for at least 15 minutes, then hold the power button for **20 seconds** to force a reset. If the charging LED does not light up, raise a ticket with category **"Hardware"**.

### 2.2 Blue Screen Error 0x0000007E

Stop code **0x0000007E (SYSTEM_THREAD_EXCEPTION_NOT_HANDLED)** is usually caused by an outdated driver. Restart, open **Company Portal > Updates**, and install all pending driver updates. If it happens more than twice in a week, raise a Hardware ticket and include the stop code.

### 2.3 Disk Full Warning

Run **Orbit Cleanup** from the Start menu, which clears temporary files and the browser cache. Do not delete files in the OrbitAgent folder; they are needed for device management.

### 2.4 Slow Performance

Restart at least once a week. If the laptop is still slow, check Task Manager for processes using more than 80% CPU and include a screenshot in your ticket.

### 2.5 Wi-Fi Keeps Disconnecting

Forget the network and reconnect. In the office, connect to **Orbit-Corp**, not Orbit-Guest.

## 3. Loss or Theft

Report a lost or stolen laptop **within 1 hour** by raising a ticket with priority **"High"** and category **"Security"**. IT will remotely wipe the device. A police report number is required for theft.

## 4. Replacement and Loaner Devices

A **loaner laptop** is available from the IT desk on the 2nd floor while your laptop is being repaired. Repairs normally take **3 to 5 working days**.

## 5. Software Installation

Approved software is installed through Company Portal. Software not in the portal needs a ticket with category **"Software Request"** and manager approval.
